# Question List

## Вхід
Файл `<КЛЮЧ>/<КЛЮЧ>-summary.md`. Якщо файлу немає — зупинись і скажи, що спершу потрібен підсумок тікета.

## Правила
- Для кожної вимоги `REQ-N` з підсумку постав щонайменше одне уточнювальне питання про межі, винятки чи граничні випадки.
- Оформлюй кожен пункт суворо у форматі `- **REQ-N** — Текст питання?`.
- Якщо в підсумку в розділі «Відкриті питання:» вже були питання — перенеси їх без змін в окремий розділ `## Відкриті питання з тікета:` (якщо їх немає — не додавай цей розділ).
- Не змінюй файл підсумку `<КЛЮЧ>/<КЛЮЧ>-summary.md`.
- Суворо дотримуйся структури, заголовків і пунктуації з `references/example.md`.

## Вихід
Збережи файл `<КЛЮЧ>/<КЛЮЧ>-questions.md` за шаблоном `references/example.md`.
